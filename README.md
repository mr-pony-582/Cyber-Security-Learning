# Cyber Security Learning Tracker

A daily learning tracker documenting my journey into cybersecurity.

This repository serves as a personal knowledge base where I record my daily progress, notes, concepts, practical exercises, tools, and resources related to cybersecurity. The goal is to maintain consistent learning, build a strong foundation, and track my progress over time across different areas of information security.

Topics may include cybersecurity fundamentals, networking, Linux, ethical hacking, penetration testing, web security, cryptography, digital forensics, threat intelligence, security operations, and other related domains.

This repository is a record of continuous learning—one day, one concept, and one step closer to becoming a better cybersecurity professional.
